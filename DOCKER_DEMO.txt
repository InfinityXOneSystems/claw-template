🚀 QUICK START - THREE METHODS

Method 1: Launch Script (Recommended)
$ ./docker-launch.sh

Method 2: Makefile Commands
$ make up

Method 3: Docker Compose
$ docker compose up -d

📋 STEP-BY-STEP LAUNCH

Step 1: Clone Repository
$ git clone https://github.com/InfinityXOneSystems/claw-template.git
$ cd claw-template

Step 2: Configure Environment
$ cp .env.docker .env
$ nano .env   # Edit with your API keys

Step 3: Launch
$ ./docker-launch.sh

Step 4: Access
Frontend:  http://localhost
Backend:   http://localhost:5000

🔍 VERIFY DEPLOYMENT

$ docker compose ps
$ curl http://localhost:5000/health
$ docker compose logs -f

✅ SUCCESS - Your system is running!
