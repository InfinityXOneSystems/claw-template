# Claw Chat - Black Theme Template

A sleek, modern chat UI template with a black theme. Perfect for building chat applications, messaging interfaces, or customer support systems.

## Features

✨ **Modern Design**
- Clean and minimal black theme
- Smooth animations and transitions
- Responsive layout (mobile-friendly)
- SVG icons for crisp visuals

🎨 **Customizable**
- Easy-to-modify CSS variables
- Modular structure
- Well-commented code

💬 **Interactive**
- Real-time message sending
- Auto-response simulation
- Smooth scrolling
- Emoji and attachment buttons

## Quick Start

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start chatting!

## Usage

### Basic Setup

Simply open `index.html` in any modern web browser. No build process or dependencies required!

### Customization

**Change Colors:**
Edit the color values in `styles.css`:
```css
background: #000000;  /* Main background */
background: #1a1a1a;  /* Secondary background */
border: 1px solid #2a2a2a;  /* Borders */
```

**Modify Messages:**
The initial messages are in `index.html`. You can add, remove, or edit them in the `<div class="chat-messages">` section.

**Add Functionality:**
Extend `script.js` to integrate with your backend API, add more features, or customize the behavior.
